# Dataset

The dataset is downloaded automatically by:

```bash
python src/download_data.py
```

Source:

https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

The source repository is maintained by IBM and is archived. See `LICENSE-ATTRIBUTION.md` for attribution information.

The CSV is intentionally not bundled in this portfolio package so the repository stays lightweight and the dataset's original distribution is respected.
